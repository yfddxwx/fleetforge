# 快捷键（shortcuts.md）

交互优先键盘流。所有视图的键位一览。

## `fleet board`（终端看板）

| 键 | 动作 |
| --- | --- |
| `j` / `↓` | 光标下移 |
| `k` / `↑` | 光标上移 |
| `d` | 派发当前任务（POST /api/tasks/:id/dispatch） |
| `c` | 取消当前任务（先确认 `[y/N]`） |
| `f` | 对运行中任务发追问（输入文本，回车发送） |
| `r` | 立即刷新（另有 1.5s 自动轮询） |
| `?` | 键位帮助 |
| `q` / `Ctrl-C` | 退出 |

注意：`d`/`c`/`f` 需要本地 server 在跑（`fleet serve`）；board 读库 +
发命令分离，看板只读 WAL，命令走 HTTP。

## `fleet task new`（内联模式事件流）

只读视图，无键位；`Ctrl-C` 中断会终止整个 agent 进程树。

## Web 控制台（M6+）

看板：
| 键 | 动作 |
| --- | --- |
| `j` / `k` | 卡片间移动 |
| `←` / `→` | 跨列移动（backlog → running → review → done） |
| `Enter` | 打开任务详情 |
| `d` | 派发选中任务 |
| `c` | 取消（确认弹窗） |
| `m` | 合并（review 列；dry-run 预演后确认） |
| `x` | 丢弃（有未提交更改时强制确认） |
| `/` | 搜索 |
| `?` | 键位帮助 |

任务详情：`1/2/3` 切换 事件流 / 转录 / diff 标签页；`f` 发追问。
