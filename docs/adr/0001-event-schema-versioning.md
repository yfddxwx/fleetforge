# ADR-0001: 事件 schema 版本化策略

状态：已接受（M0）

## 背景
多种 agent CLI 的输出被归一化为统一事件流，server、web、cli 都是消费端。
schema 必然演进；消费端与历史数据不能每次演进都重写。

## 决策
- `SCHEMA_VERSION`（当前 1）标注在事件信封 `schemaVersion` 字段。
- **新增** kind 或可选字段 = minor：版本号不变，消费端必须容忍未知 kind（丢弃或透传）。
- **删除/收紧/改义** = major：版本号 +1；server 摄取时做降级转换，老 kind 白名单映射。
- 事件落库保存摄取时的 schemaVersion；回放按版本解释。
- `raw` kind 是永久逃生舱：驱动解析不了的行归一化为 `raw` 而非报错。

## 后果
+ 消费端代码简单：只认 v1 信封。
+ 历史事件永久可解释。
− 驱动解析器必须保守：宁可落 `raw`，不可丢行。
